# Icon

`icon.png` is the DeepSeek Harness program icon (512x512), copied from the
`dsh` installation at `~/.local/share/dsh/dsh.png`. It is the harness's own
mark, used here so the desktop entry and window match the CLI. Replace it if
you redistribute this shell under a different name.

`scripts/install.sh` renders the hicolor sizes from this file.
